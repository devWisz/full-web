URL Shortener
Shortens your long and unclean urls in second

Try it live:
https://full-web-neon.vercel.app/

A clean and minimal URL shortener built with HTML, CSS, and JavaScript. It converts long links into short ones using the TinyURL API and stores recent results in local storage.

Features

Shortens URLs instantly using TinyURL

URL validation (HTTP/HTTPS only)

Copy shortened link to clipboard

Open shortened link in a new tab

Responsive UI
